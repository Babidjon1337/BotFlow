# BotFlow — контекст дизайна

## Design Context

### Users
- **Приоритетная аудитория:** эксперты и блогеры (продают курсы, доступы в каналы), консультанты и репетиторы (запись, консультации), малый бизнес (магазины, услуги). 25–45, не технари.
- **Ключевая особенность:** НЕ хотят разбираться в платформе и коде, НЕ хотят «рисовать схемы» в классических конструкторах ботов, НЕ хотят думать про лимиты сообщений. Им нужны **готовые решения** — выбрал сценарий, ответил на вопросы, бот работает.
- **Job to be done:** «Продавай в Telegram, пока я занимаюсь делом» — бот знакомит с предложением, принимает оплату, выдаёт результат.
- **Боли:** клиенты теряются в личке; ручная рутина и ответы ночью; оплата — переводами «на карту»; страх «сложного IT» и дорогих разработчиков.
- **Эмоции интерфейса:** спокойная уверенность, «это мне по силам», лёгкость, доверие к деньгам.

### Brand Personality
- Три слова: **надёжно, просто, по-деловому дружелюбно**.
- Тон текстов: разговорный-деловой, без канцелярита и хайпа; короткие фразы, конкретика вместо обещаний.
- Никакого «инновационного disruptive» пафоса и фейковых цифр.

### Aesthetic Direction
- Светлая, воздушная премиум-эстетика. Ключевые референсы (v5, по ним сделано направление): **Passport OCR SDK** (телефон из нижнего края, чипы вокруг), **Nuum** (продукт-дашборд как герой), **Relink** (атмосфера на всю секцию, тилт карточек), **Linkora** (пастельные контейнеры, 3D-объекты), **Remail** (3D-акцент в заголовке), **FincEd** (tilt-композиция, inline-пилюля в H1).
- Типографика (v5): display — **Onest 800**, трекинг −0.04…−0.045em, line-height 1.04–1.06, H1 clamp(42→76px), H2 clamp(34→54px) — референсный масштаб; акцентное слово — градиент blue→violet (background-clip: text). **Unbounded — только акциденция**: логотип, кикеры секций (11px, uppercase, +0.14em, с тире-градиентом), все цифры (990 ₽, +1 500 ₽, статистика), номера шагов. В заголовках Unbounded запрещён (ломает длину русских слов). Body: Onest 400/500, 17–18px/1.65, #475467.
- Цвета: почти-белая база (#fcfcfd), чернильный #101828, синий-бренд #2563eb, фиолетовый акцент #7c3aed; пастельные радиальные засветки blue→violet→pink (8–14% opacity) на всю секцию — «атмосфера вместо панелей»: продукт парит на странице, без карточек-рамок вокруг hero.
- Чёрная pill-кнопка — главный CTA (56px); бейджи и чипы с мягкими тенями.
- Тени: многослойные, размытые (float: 0 24px 60px −16px rgba(16,24,40,.16–.18)); рамки 1px #e4e7ec как дополнение.
- Отступы: секции 88–96px, карточки 24–32px, контейнер 1180px. «Воздух = уверенность».
- Радиусы: карточки 20px, панели 28px, кнопки/бейджи — pill.
- **Глоу — сдержанно** (правило пользователя): засветки 7–14% opacity, белый прожектор за телефоном ≤0.7; никаких неоновых свечений и грубых halo.
- Иллюстрации сценариев: единая серия soft-3D рендеров (matte clay, пастель бренда, светлые фоны, без текста) — `design/scenarios/scenario-{courses,booking,shop,brief}.jpg`; исходники ChatGPT удаляются после обработки.

### Hero (v5) — продуктовая сцена
- Центрированная композиция: overline → H1 (2 строки, градиентное акцент-слово, inline-пилюля «Черновик — 0 ₽») → подзаголовок → CTA → trust-строка → большая сцена снизу.
- Сцена: CSS-телефон (324px, обрезан нижним краем секции) с реальным чатом продажи; слева/справа — UI-стейты (конструктор-чеклист, статистика недели) с тилтом ∓3–4°; пунктирные орбиты (2 кольца) вокруг.
- **Движение (нежное, только вертикаль)**: все 6 карточек сцены плавают вверх-вниз (translate, без scale-растяжений): боковые ±7px (7.5–9s), орбитальные ±10px (6.5–8s, разные фазы). Маленькие орбитальные карточки — всегда ПЕРЕД телефоном (z6), без оборотов вокруг. Кольца — градиентные «бусины» (SVG stroke-dasharray 1×, linecap round, blue→violet / violet→pink), вращаются в противофазе (60s/44s reverse), по ним едут 3 светящихся спутника-точки. `prefers-reduced-motion` всё статично.
- Anti-references: перегруженные тёмно-неоновые «крипто» лендинги, stock-фото, руки/люди ради декора в hero.

### Цена (v5) — стресс-тест вместо pricing-карточки
- Слева текст+CTA, справа панель-демо: счётчик нагрузки 5→50→500→5 000 (авто-цикл 2.6s, кликабельные степперы, пауза на hover); строка «конструкторы» краснеет и растёт (990→49 000 ₽, метка «растёт с объёмом»), строка BotFlow — 990 ₽ в зелёной «защите» с меткой «фиксированная цена».
- Принцип: преимущество показывается механикой, а не графиками и бенто-сетками.

### Implementation Defaults
- Фронтенд: React 19 + TypeScript + Vite + Tailwind v4 (токены в `frontend/src/index.css`), Base UI, framer-motion, иконки lucide-react, шрифт Onest.
- Бэкенд: FastAPI + SQLAlchemy async + aiogram + APScheduler; TMA-авторизация через initData.
- Дизайн-артефакты (welcome, DS) сначала в standalone HTML (`welcome-screen.html`, git-ignored), затем перенос в React.
- Токены нейминга: `--n-*` нейтрали, `--b-*` синий, `--v-*` фиолетовый, семантические `--background/--card/--border/--primary…`, радиусы `--radius-control/card/sheet`, тени `--shadow-xs/card/float`.
- Тёмная тема обязательна (html.dark), но светлая — основная.

### Design Principles
1. **Показывай результат, а не обещай** — в хиро живой продуктовый момент (чат продажи + орбита событий владельца), а не абстрактные Benefits.
2. **Простота — это контент**: каждый экран отвечает на страх «я не разберусь» (готовый сценарий, 3 шага, без кода).
3. **Воздух и мягкость = премиум**: щедрые отступы, пастельная атмосфера на всю секцию, мягкие многослойные тени; глоу — дозированно.
4. **Продукт — герой**: крупный CSS-мокап реального UI вместо декоративных панелей; движение вокруг продукта создаёт глубину (перед/за телефоном), но не мешает чтению.
5. **Один главный CTA на экран** — чёрная pill-кнопка; вторичные действия — ghost.
6. **Деньги — свои, цена — фиксированная**: «касса клиента», «990 ₽/мес», «черновик — 0 ₽», «без лимитов»; преимущество цены показываем стресс-тестом, без фейковых метрик.
7. **Иллюстрации — серией**: все 3D-визуалы в одном стиле (материал, свет, палитра), только через IMAGE REQUEST по формату AGENTS.md.
