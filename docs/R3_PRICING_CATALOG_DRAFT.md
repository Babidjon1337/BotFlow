# Черновик PRODUCT_MODEL — каталог тарификации R3

Статус: требует утверждения владельцем продукта. Этот документ не меняет
текущий billing, checkout или публичные цены.

## Что уже принято

- Подписка и право публикации относятся к конкретному боту, не к слоту аккаунта.
- Черновик и тестирование владельцем бесплатны; trial отсутствует.
- Одна доступная платформа входит в базовую конфигурацию, дополнительные
  платформы оплачиваются отдельно.
- Нет лимитов сообщений, лидов и подписчиков как тарифицируемого ресурса.
- Подарок даёт подходящую конфигурацию бота; дополнительные возможности
  оплачиваются отдельно.

## Сущности тарификации

| Сущность | Назначение | Связь |
|---|---|---|
| PricingCatalog | Версионированный опубликованный набор правил | один активный для региона/валюты |
| PriceItem | Цена сценария, платформы или модуля | принадлежит каталогу |
| BotConfiguration | Снимок выбранных возможностей перед оплатой | принадлежит боту |
| BotQuote | Детерминированный расчёт из каталога и конфигурации | создаётся на checkout |
| BotSubscription | Оплаченное право публикации | один бот, период/статус |
| GiftGrant | Бесплатное или льготное право на совместимую конфигурацию | применяется к одному боту |
| GatewayConnection | Не является товаром; нужна для автопродажи | принадлежит аккаунту |

## Поля PricingCatalog и PriceItem

| Поле | Зачем |
|---|---|
| catalog_id, version, status, effective_from/to | воспроизводимость старых расчётов |
| currency, region, tax_mode | корректная сумма и чековые правила |
| item_code, item_kind | стабильная ссылка из quote/subscription |
| scenario_type / platform_code / module_code | условие применимости |
| billing_period | месяц, год или иной период |
| amount_minor, included_quantity | цена без float и включённая первая платформа |
| eligibility_rule | условия, например только новая публикация |
| upgrade_rule, proration_rule | изменение уже оплаченной конфигурации |
| visible_name, description | честный UI-copy без дублирования бизнес-правил |

## Следующие из архитектуры варианты монетизации

| Вариант | Совместимость с моделью | Риск/следствие |
|---|---|---|
| Базовая подписка на бот + доплата за платформы | полностью соответствует | нужен период и правила смены конфигурации |
| Подписка на бот + платные будущие модули | соответствует | нельзя продавать до реализации capability |
| Годовой план со скидкой | соответствует | нужен выбор автопродления и возвратов |
| Gift Grant на базовую конфигурацию | прямо предусмотрен | нужен scope, срок и число активаций |
| Разовая пожизненная публикация | конфликтует с уходом от lifetime-слотов, но возможна как BotSubscription без срока | требует отдельного решения о поддержке |

## Решения, требующие утверждения

| Решение | Нужен выбор | Влияние |
|---|---|---|
| Базовый товар | цена и период для Telegram + «Воронка продаж» | BotQuote, checkout, BotSubscription |
| Дополнительная платформа | цена, доступность и правило первой включённой | PricingCatalog и UI-конфигуратора |
| Платные модули | перечень и цена либо явное отсутствие в v1 | capability catalog |
| Годовой план | есть ли, размер скидки, автопродление | billing и возвраты |
| Изменение конфигурации | сразу, с prorate или в следующий период | quote/subscription transition |
| Gift Grant | срок, количество активаций, что именно покрывает | admin flow и entitlement |
| Lifetime-вариант | запрещён полностью или допустим только на одного бота | миграция legacy licenses |
| Налоги/чеки | кто формирует чек, НДС/самозанятый/ИП, валюта | provider adapters и юридические тексты |
| Просрочка/повторная оплата | grace period, дата паузы, правила возобновления | scheduler и lifecycle `paused/subscription` |
