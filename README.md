# BotFlow

**BotFlow** (ранее FunnelGenius / Bot Father) — это продвинутая SaaS-платформа для создания и управления автоматизированными воронками продаж в Telegram. Платформа позволяет пользователям без навыков программирования создавать ботов, которые продают их услуги, курсы или товары 24/7.

## 🚀 Основные возможности

- **Drag-and-Drop воронки**: Создание многошаговых воронок (сообщения, задержки, кнопки, оплата) через удобный веб-интерфейс (Mini App).
- **Встроенная монетизация**: Подключение YooKassa (и потенциально других провайдеров) для автоматического приема платежей внутри воронок клиентских ботов.
- **Умные "дожимы" (Follow-ups)**: Система автоматических напоминаний, которые возвращают пользователей, не завершивших покупку, увеличивая конверсию.
- **SaaS-биллинг**: Главный бот платформы продает доступ к функционалу по подписке (бесплатная лицензия и PRO-тариф).
- **Telegram Mini App**: Весь интерфейс управления (дашборд) работает прямо внутри Telegram в виде красивого веб-приложения, обеспечивая бесшовный пользовательский опыт (Telegram Web Apps).

## 🛠 Технологический стек

### Бэкенд
- **Python 3.10+**
- **FastAPI**: Высокопроизводительный веб-фреймворк для API и обработки вебхуков.
- **Aiogram 3.x**: Асинхронный фреймворк для работы с Telegram Bot API.
- **PostgreSQL**: Реляционная база данных для хранения конфигураций воронок, пользователей и платежей.
- **SQLAlchemy & Alembic**: ORM и инструмент для миграций базы данных.
- **APScheduler**: Планировщик фоновых задач (для автоматических напоминаний и проверки подписок).
- **YooKassa API**: Интеграция с платежным шлюзом.

### Фронтенд (Mini App)
- **React 18** (через Vite)
- **TypeScript**: Строгая типизация для надежного кода.
- **Tailwind CSS**: Утилитарный CSS-фреймворк для быстрой стилизации и поддержки темной темы.
- **Framer Motion**: Плавные анимации и переходы интерфейса.
- **Zustand / Context**: Управление состоянием (корзины, авторизация, темы).
- **React Flow**: (Используется для визуального редактора логики воронок).

## 📁 Структура проекта

```text
.
├── backend/                  # Python FastAPI бэкенд
│   ├── config.py             # Централизованная конфигурация и загрузка .env
│   ├── main.py               # Точка входа FastAPI, настройка вебхуков и маршрутизатора
│   ├── api_router.py         # Основные API эндпоинты
│   ├── database/             # Модели SQLAlchemy и CRUD запросы
│   ├── handlers/             # Обработчики Aiogram (Главный бот и клиентские)
│   ├── services/             # Бизнес-логика (Платежи, Планировщик, Оповещения)
│   ├── venv/                 # Виртуальное окружение
│   └── alembic/              # Миграции базы данных
├── frontend/                 # React Vite фронтенд
│   ├── src/
│   │   ├── components/       # UI компоненты (Sidebar, Sheets, Tabs и др.)
│   │   ├── services/         # API клиенты и интеграция с Telegram WebApp
│   │   ├── types.ts          # Общие TypeScript типы
│   │   └── App.tsx           # Главный компонент, роутинг и обработка авторизации
│   └── public/               # Статические файлы (логотипы, ассеты)
└── deploy/                   # Конфигурации для деплоя (Nginx, Systemd)
```
